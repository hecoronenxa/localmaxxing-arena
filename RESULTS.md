# Results

Generated by `scripts/summarize.py`; do not edit by hand. Local recipes are ranked by score; official APIs are reference lines, and *vs API* is the gap to the same model's API reference (full runs only). Smoke runs (k < protocol) are noisy.

Score = mean reward over all trials; a trial that errors or times out scores 0. `err` = trial raised an exception (timeout, context overflow, infrastructure).
